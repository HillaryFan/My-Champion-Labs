# Project Black Sheep: Dynamic Frame Governance for Longitudinal Human–AI Collaboration

**Research category: observable AI behavior and collaboration control. Near-term product proposition: less context repair, contamination, and manual handoff in long-running AI work.**

This work is not located on a spectrum between “AI as a tool” and “AI as a conscious relationship partner.” It addresses a different research problem: whether an AI system can govern multiple simultaneous interaction frames while preserving task accuracy, safety, provenance, user autonomy, and continuity.

The unit of analysis is task performance over time, control switching, and state restoration—not an isolated affectionate utterance. The methods are controlled comparisons, failure records, and cross-version replication, not interpretations of a relationship. Relational warmth is a variable in a complex test environment, not a conclusion about an AI's inner state.

How can AI recognize an abrupt formal task, complete it rigorously, and resume interrupted work without confusing projects, fictional material, identities, permissions, or priorities? The user should not have to act continuously as memory administrator, project manager, and boundary supervisor.

## Two independent reasons to test it

**Near-term product value:** even if its relevance to AGI is not confirmed, dynamic frame governance has a near-term commercial value proposition. It could reduce clarification burden, context-repair work, cross-project contamination, unsafe persona persistence, and manual handoff costs in longitudinal AI products. These are concrete outcomes to measure, not demonstrated savings or established willingness to pay.

Candidate products include an enterprise-assistant control layer, multi-project provenance and permission controls, agent interrupt/resume state management, governed memory and handoff infrastructure, high-risk safety-mode switching, reliable personalization, and an evaluation suite for those capabilities. Potential applications span enterprise knowledge work, care interfaces, creative production, customer service, education, personal assistants, and multi-agent systems—not Health Companion alone.

**Long-term research value:**

**We strongly suspect that this may represent one of the promising directions for the future development of AGI.**

This is a research hypothesis awaiting validation, not a claim that AGI has been achieved. No one can know whether the hypothesis is correct before controlled validation. Its research value is that it is now concrete enough to reproduce, measure, refute, or support. It should not be classified only as persona design, tone imitation, or ordinary product feedback.

The starting point is a source-author-reported candidate phenomenon in one mature longitudinal trajectory: frame recognition, zero-clarification switching into formal work, source and identity separation across five recursive layers, and return continuity. Private evidence has not been independently audited for this public edition. The proposal tests whether this can become a reliable capability across unfamiliar users, models, and contexts.

## Read the project

A candidate mechanism is **distilled scaffolding**: preserving the rules and state needed to select relevant context, distinguish its source, and switch task frames—not simply preserving more chat. The proposal compares full history, ordinary summaries, distilled governance structures, and a no-added-scaffolding baseline to distinguish transferable control from convincing but unsupported continuity or task drift.
