# AI 健康照護夥伴

人不是活在表格裡。吃了什麼、哪裡不舒服、作息怎麼變了，常常是在聊天中才說出來。到了需要別人協助或準備回診時，本人和支持者又得把這些片段重新拼一次。

**AI 健康照護夥伴不是另一個衛教聊天機器人，而是一個介於日常生活與正式照護之間、具有人性化互動並由本人控制的轉譯與協作層。**

它先接住自然敘述，再提出候選觀察，讓本人確認、修改或拒絕。經核准的少量資料，才依授權整理成看得見來源、缺漏和不確定性的三日摘要或回診 brief。要驗證的價值，是減少重複紀錄與解釋，讓需要協助的人不用因此接受全天監看。

先讀[主提案 V3](MAIN_PROPOSAL_V3.md)。依 2026-09-17 的有限市場掃描，尚未確認單一產品以公開資料展示這套完整組合；這不等於沒有競品，也不代表已有護城河。現階段仍是產品提案，預期效益需要測試。

V3 於 2026-09-20 依作者指示新增。英文為主要閱讀語言，中文另行寫作，保留相同的價值主張、流程與證據狀態。受控 V2 原始檔及歷史公開版本不變；[版本紀錄](../VERSION_HISTORY.md)說明文件適用關係，[來源紀錄](../governance/PROVENANCE.md)保留原始日期與雜湊。

Health Companion 是這項研究擬議的高風險應用案例：自然陪伴要能正確切換到安全模式，而且同意、記憶、報告與交接的規則仍要成立。這項連結不是已完成的 AGI 證據。

本專案是概念、產品要求與待驗證的原型計畫，不是已上市或經臨床驗證的醫療系統。AI 不取代醫師、護理師、糖尿病衛教師或緊急服務，不診斷、不開藥，也不自行調整胰島素或其他藥物。

本公開版本不包含真實參與者身分對照、病況、藥袋、醫療照片、私人報告、Email 截圖、商務證據包或家庭初始化指令全文。產品主題涉及糖尿病，不代表對任何真實人物健康狀況的披露。
