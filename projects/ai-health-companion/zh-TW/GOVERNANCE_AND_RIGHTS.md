# 治理與智慧財產權邊界

本頁為[英文治理規格](../governance/GOVERNANCE.md)與[英文權利聲明](../governance/RIGHTS_AND_DISCLOSURE.md)的中文重點說明，不新增不同授權條款。

## 同意與權限

參與、保存、人格、標籤、提醒、報告接收者及特殊升級安排應有可理解且適當分開的選擇。拒絕可選功能不應失去一般支持。本人可暫停、撤回、更正或提出刪除請求，但必須如實告知技術及保留限制。

支持者只取得獲准欄位與報告；家庭關係不自動授予資料或醫療權限。代理決策需另有經審查的權限基礎，不能由年齡或診斷推定。各參與者隔離需技術測試，資料夾名稱不是存取控制，即使 repository 私人亦然。

## 資料生命週期與安全

只蒐集必要資料，保留來源；一般候選紀錄先讓本人確認，再依目的及同意寫回。完整聊天、健康事件、標籤與報告分層。需驗證平台儲存、log、備份、匯出、副本與刪除，而不是只靠提示詞說忘記。

醫療規則由合格人員核准、版本化及測試，不由模型自行改寫。安全模式優先；明定無回覆、傳送失敗、值守範圍與替代求助路徑。聊天通知不是保證有人監測或提供緊急救援。

## 公開邊界

公開內容只含去識別化產品說明、合成測試、治理、來源雜湊及參考索引。不放原始附件、真人病況或身分對照、藥袋、醫療照片、私人報告、聯絡資料、Email 截圖、商務證據包、家庭初始化全文或敘事作品全文。

敏感資料不得以 private 資料夾之名放進公開 repository、Git history、issue、PR 或 release。角色替換不等於匿名性保證，仍須檢查間接辨識資訊。若誤公開，後續刪除 commit 不能保證移除舊版、快取或他人副本。

## 智慧財產權

既有[repository NOTICE](../../../NOTICE.md)與 All rights reserved 持續適用；不新增開源授權。公開閱讀不等於允許重製、商業化、再授權、衍生商業框架或宣稱獲背書。另行獲准的使用仍依書面條款與適用法律辦理。

EIP 與 Ephemeral Intelligence Protocol 的 proprietary 聲明保持不變。公開摘要不披露完整 EIP 方法，也不授予完整 middleware 或受控設計的實作權利。第三方出版品、名稱及商標依各自權利與條款使用，不因被引用而被重新授權。

本聲明不宣稱已獲專利、已註冊商標、擁有一般概念或第三方知識，也不保證法律效力。公開披露可能影響保密及其他保護策略，需要時應另請合格專業人員審查。

GitHub 平台條款仍允許瀏覽及 fork 公開 repository，權利聲明不能覆蓋平台條款或法定權利。公開資料夾不是保密管道，敏感設計必須繼續不公開。參見 [GitHub 授權說明](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/licensing-a-repository)。
